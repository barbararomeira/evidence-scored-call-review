# The message (example)

> Replace this file with your own positioning. It is the human-readable half of `message_rubric.json`;
> the extractor is given both, so the words here matter.

A generic B2B SaaS company sells software to operations teams. Twelve months ago it sold
"reporting". It now sells an operating system for the work itself, and the sales team is
supposed to say so. The six elements below are what "saying so" means.

## 1. The problem
Teams find out what went wrong after it has already cost them the week. Managers spend their
mornings assembling a picture instead of acting on one.

## 2. The category
An operating layer for how the team runs, not a reporting tool bolted onto what they already have.

## 3. See what is happening
The current state is visible without chasing anyone for an update.

## 4. Be told, not go looking
The system brings the exception to the person who owns it, rather than waiting to be queried.

## 5. What no other system can do
The incumbent stack records transactions. It cannot see the work between them, which is where
the loss happens.

## 6. Value that lasts
The gain does not decay after rollout, because the daily routine changes rather than a one-off
project delivering a number.
