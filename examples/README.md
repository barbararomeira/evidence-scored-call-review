# Examples

Committed output, so you can see what this produces before cloning anything.

| File | Produced by |
|---|---|
| `sample_day_run.txt` | `python3 run_day.py --mock` |
| `sample_coaching_R-02.md` | same run — the rep who covers the promises but never frames the problem |
| `sample_coaching_R-05.md` | same run — the rep who is genuinely on message |

Regenerate with the two commands above. If they ever differ from what is committed here, the
committed version is stale, not the code.
